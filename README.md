# Culture Mechanics ChatGPT Project Workflow

## Instructions for participants

The following sections are written to be copied and sent to people who have no
prior knowledge of this repository or of Culture Mechanics.

### English

You can use the files provided with these instructions to ask ChatGPT to explain a
historical, social, political, organizational, or personal phenomenon through the
Culture Mechanics framework. You do not need to know the framework's terminology,
and you may ask your question in your preferred language and at an ordinary level
of detail.

The screenshots show the English ChatGPT interface available when this package was
created. Labels, language, or layout may change as the interface evolves.

1. Select **Projects** in the ChatGPT sidebar
   ([screenshot](docs/10-project-selection.png)).
2. On the Projects page, select **New**
   ([screenshot](docs/20-new-project.png)). Enter a descriptive
   project name, such as `culture-mechanics-questions`, keep **Default memory** unless
   you have a reason to choose another setting, and select **Create project**
   ([screenshot](docs/30-create-project.png)).
3. In the new Project, open the three-dot menu at the upper right
   ([screenshot](docs/40-settings-and-sources.png)) to open
   **Project settings**. Open `0000-culture-mechanics.project-instructions.md`, copy
   its complete contents, paste them into the **Instructions** field, and close the
   settings window
   ([screenshot](docs/50-settings.png)).
4. Select **Sources**, then **Add sources**, and upload
   `0000-culture-mechanics.guide.md` and
   `build/0000-culture-mechanics.core.md`. Confirm that both appear in the source
   list ([screenshot](docs/60-sources.png)). The screenshot shows
   `guide(1).md` because that local copy had acquired a duplicate-file suffix; use
   the `0000-culture-mechanics.guide.md` supplied in this package.
5. Return to **Chats**, start a chat in the Project, and ask your question naturally.
   You can optionally begin with: “Please analyze the following question through
   Culture Mechanics, using the two-pass workflow: …”
6. ChatGPT should first return a relevance assessment rather than a full answer.
   Check whether it understood your question and whether the proposed theory
   sections seem relevant. If the core source is sufficient, reply “continue.”
7. If the relevance assessment says that a supplementary source is required, find
   the named individual Markdown file under `build/`, add it to the Project sources,
   and then ask ChatGPT to continue. If the named file is unavailable, do not ask
   ChatGPT to invent its contents. If your question asks for the exact practical
   method of implementing a culture and the assessment names *Systems Leadership:
   Creating Positive Organisations*, that is an external book not included in this
   package. Read the book rather than asking ChatGPT to reconstruct its method from
   the supplied theory files.

The second response should give the actual explanation, distinguish claims made by
the theory from external facts and case-specific inferences, and state limitations
or alternative interpretations. For a substantially different question, start a
new chat in the same Project so that the first-pass source selection begins afresh.

### Deutsch

Mit den zusammen mit dieser Anleitung bereitgestellten Dateien können Sie ChatGPT
bitten, ein historisches, gesellschaftliches, politisches, organisatorisches oder
persönliches Phänomen aus der Perspektive der Kulturmechanik zu erklären. Sie müssen
die Fachbegriffe der Theorie nicht kennen und können Ihre Frage in Ihrer bevorzugten
Sprache und in einer alltäglichen Form stellen.

Die Bildschirmfotos zeigen die englische ChatGPT-Benutzeroberfläche zum Zeitpunkt
der Paketerstellung. Beschriftung, Sprache oder Anordnung können sich mit der
Benutzeroberfläche ändern.

1. Wählen Sie in der ChatGPT-Seitenleiste **Projects** (Projekte)
   ([Bildschirmfoto](docs/10-project-selection.png)).
2. Wählen Sie auf der Projektseite **New** (Neu)
   ([Bildschirmfoto](docs/20-new-project.png)). Geben Sie einen
   aussagekräftigen Projektnamen ein, zum Beispiel `culture-mechanics-questions`,
   behalten Sie **Default memory** (Standardspeicher) bei, sofern Sie keinen Grund
   für eine andere Einstellung haben, und wählen Sie **Create project** (Projekt
   erstellen)
   ([Bildschirmfoto](docs/30-create-project.png)).
3. Öffnen Sie im neuen Projekt über das Dreipunktmenü oben rechts
   ([Bildschirmfoto](docs/40-settings-and-sources.png)) die
   **Project settings** (Projekteinstellungen). Öffnen Sie
   `0000-culture-mechanics.project-instructions.md`, kopieren Sie den vollständigen
   Inhalt, fügen Sie ihn in das Feld **Instructions** (Anweisungen) ein und schließen
   Sie das Einstellungsfenster
   ([Bildschirmfoto](docs/50-settings.png)).
4. Wählen Sie **Sources** (Quellen) und danach **Add sources** (Quellen hinzufügen).
   Laden Sie `0000-culture-mechanics.guide.md` und
   `build/0000-culture-mechanics.core.md` hoch. Prüfen Sie, ob beide in der
   Quellenliste erscheinen
   ([Bildschirmfoto](docs/60-sources.png)). Im Bildschirmfoto
   erscheint `guide(1).md`, weil diese lokale Kopie bereits einen Namenszusatz für
   eine Dateidublette erhalten hatte. Verwenden Sie die in diesem Paket enthaltene
   Datei `0000-culture-mechanics.guide.md`.
5. Kehren Sie zu **Chats** zurück, beginnen Sie im Projekt einen Chat und stellen Sie
   Ihre Frage in natürlicher Sprache. Sie können zum Beispiel so beginnen: „Bitte
   analysiere die folgende Frage mithilfe der Kulturmechanik und verwende dabei das
   zweistufige Verfahren: …“
6. ChatGPT sollte zunächst eine Relevanzprüfung und noch keine vollständige Antwort
   liefern. Prüfen Sie, ob Ihre Frage richtig verstanden wurde und ob die
   vorgeschlagenen Theorieabschnitte passend erscheinen. Wenn die Kerndatei
   ausreicht, antworten Sie mit „weiter“.
7. Falls laut Relevanzprüfung eine ergänzende Quelle erforderlich ist, suchen Sie die
   genannte einzelne Markdown-Datei unter `build/`, fügen Sie sie den Projektquellen
   hinzu und bitten Sie ChatGPT danach fortzufahren. Falls die genannte Datei nicht
   verfügbar ist, bitten Sie ChatGPT nicht, ihren Inhalt zu erfinden. Wenn Ihre Frage
   nach dem genauen praktischen Verfahren zur Umsetzung einer Kultur fragt und die
   Relevanzprüfung *Systems Leadership: Creating Positive Organisations* nennt,
   handelt es sich um ein externes Buch, das nicht in diesem Paket enthalten ist.
   Lesen Sie das Buch, statt ChatGPT aufzufordern, seine Methode aus den
   bereitgestellten Theoriedateien zu rekonstruieren.

Die zweite Antwort sollte die eigentliche Erklärung liefern, Aussagen der Theorie
von externen Tatsachen und fallspezifischen Schlussfolgerungen unterscheiden sowie
Grenzen oder alternative Deutungen nennen. Beginnen Sie für eine wesentlich andere
Frage einen neuen Chat im selben Projekt, damit die Quellenauswahl wieder mit dem
ersten Schritt beginnt.
